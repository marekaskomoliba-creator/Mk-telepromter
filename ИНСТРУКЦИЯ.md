# MK Teleprompter — как получить APK

## Что это
Исходный Android-проект телесуфлёра. Камера телефона не используется. Есть текстовый экран, горизонтальное и вертикальное отражение, выбор языка распознавания (литовский, русский, польский, английский), голосовое отслеживание сценария, ручное перемещение, размер текста и импорт TXT.

## Как собрать APK через GitHub

1. На компьютере или телефоне откройте https://github.com и войдите в аккаунт (или создайте бесплатный).
2. Нажмите **New repository**.
3. Назовите репозиторий `mk-teleprompter`, выберите **Public** или **Private**, нажмите **Create repository**.
4. Распакуйте ZIP-архив проекта на компьютере.
5. В репозитории нажмите **Add file → Upload files**.
6. Загрузите ВСЁ содержимое папки проекта (включая скрытую папку `.github`). Важно: в корне репозитория должны находиться `settings.gradle`, `build.gradle`, папка `app` и папка `.github`.
7. Нажмите **Commit changes**.
8. Откройте вкладку **Actions**. Должен запуститься процесс **Build Android APK**. Если GitHub попросит разрешить Actions, нажмите разрешение.
9. Дождитесь зелёной галочки у сборки. Откройте завершённый запуск **Build Android APK**.
10. Внизу страницы найдите **Artifacts** и скачайте `MK-Teleprompter-APK`.
11. Распакуйте скачанный архив. Внутри будет `app-debug.apk`.
12. Отправьте APK на телефон Android и откройте его. Если Android спросит, разрешите установку приложений из этого источника.

## Как пользоваться

1. Откройте MK Teleprompter.
2. Выберите язык речи: Lietuvių, Русский, Polski или English.
3. Вставьте текст в поле или нажмите **Įkelti tekstą**, чтобы загрузить TXT-файл.
4. Включите нужное отражение: **Veidrodis H** — по горизонтали, **Veidrodis V** — по вертикали. Можно включить оба.
5. Нажмите **Pradėti / sustabdyti balsą** и разрешите доступ к микрофону.
6. Начните читать. Приложение распознаёт фразы и ищет их место в сценарии, затем прокручивает текст.
7. Если нужно, используйте **Atgal**, **Toliau**, **A−**, **A+**.

## Важные ограничения первой версии

- Качество и доступность распознавания зависят от установленного на телефоне Android сервиса распознавания речи и его поддержки выбранного языка. Для стабильного распознавания обычно нужен интернет.
- В первой версии реализовано базовое сопоставление распознанных слов со сценарием. При сильном перефразировании, шуме или длинных паузах позиция может определяться неточно.
- Для загрузки сейчас поддерживается обычный TXT. DOCX можно скопировать в поле или сохранить как TXT.
- Это debug APK для личной установки, не подписанный релиз для Google Play.

## Если сборка не проходит
Откройте вкладку Actions, выберите красный запуск и скопируйте последнюю часть лога ошибки. Её можно прислать для исправления проекта.
